step 1: clone the repo
step 2: go to ./Project_Library/on_board_pcb
step 3: double click on_board_pcb.kicad_pro

if that doesnt work, open the project file (.kicad_pro) from the file tab on kicad

step 4: open schematic editor > preferences tab > manage symbol libraries 
step 5: add the .kicad_sym file (located in Avionics_Symbols directory) and save
step 6: open footprint editor > preferences tab > manage symbol libraries
step 7: add the .pretty folder (located in Avionics_Footprints directory) and save

you are now ready to start building!
