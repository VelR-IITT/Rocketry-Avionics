step 1: clone the repo \
step 2: go to ./Project\_Library/on\_board\_pcb \ 
step 3: double click on\_board\_pcb.kicad\_pro \ 
\
if that doesnt work, open the project file (.kicad\_pro) from the file tab on kicad \ 
\ 
step 4: open schematic editor > preferences tab > manage symbol libraries \ 
step 5: add the .kicad\_sym file (located in Avionics\_Symbols directory) and save \
step 6: open footprint editor > preferences tab > manage symbol libraries \
step 7: add the .pretty folder (located in Avionics\_Footprints directory) and save \
\
you are now ready to start building! \

if you wish to make changes to the repo contact [Pratham](https://github.com/prathamchintamani) \
